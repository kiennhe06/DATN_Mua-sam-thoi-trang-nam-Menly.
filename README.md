# Menly (MenShop) — Ứng dụng thương mại điện tử thời trang nam

Đồ án gồm 4 phần:

- **database/** — Cơ sở dữ liệu (PostgreSQL / Supabase): các file SQL tạo bảng + dữ liệu mẫu.
- **backend/** — Máy chủ xử lý (Node.js + Express + TypeScript).
- **admin/** — Trang quản trị cho nhân viên (Next.js).
- **frontend/** — Ứng dụng điện thoại cho khách hàng (Flutter).

## Thứ tự dựng
1. Tạo cơ sở dữ liệu trên Supabase (xem `database/README.md`).
2. Chạy backend (xem `backend/README.md`).
3. Chạy trang quản trị (xem `admin/README.md`).
4. Chạy app (xem `frontend/README.md`).
